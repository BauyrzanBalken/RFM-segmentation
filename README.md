# RFM-segmentation
# Сегментация клиентов по RFM-модели

## Задача
Розничная компания (датасет Online Retail II, UK, 2009-2011) не различала 
клиентов по ценности — маркетинговые рассылки и удержание были одинаковыми 
для всех. Нужно было выявить, кто приносит основную выручку и кто под риском ухода.

## Инструменты
Python (pandas) → PostgreSQL (Neon, SQL: CTE, оконные функции NTILE) → 
сегментация → Power BI

## Ключевые выводы
- Из 1,067,371 транзакций после очистки (гостевые покупки, возвраты, дубликаты) 
  осталось 779,425 строк (73%)
- **Champions — 22.8% клиентов, но 68.7% всей выручки** (классическое правило Парето)
- Сегмент "At Risk" (345 клиентов, средняя частота 7.7 заказов, не покупали 
  в среднем 342 дня) — приоритет для реактивационной кампании: раньше были 
  активными, сейчас под риском полного ухода
- "Lost" — 1277 клиентов (21.7%), но только 1.9% выручки — низкий приоритет 
  для маркетинговых затрат
